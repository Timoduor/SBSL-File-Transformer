**Description**

File Extraction Transformation and Loading Tool (ETL)

*Used to do conversion of files to desired format*

---

## Requirements

You’ll need the following software to run the project

1. Visual studio 2022
2. MariaDB and HeidiSQL
3. Rebex to simulate SFTP server or any other SFTP server software
4. MailSlurper to simulate email server (optional)
5. Required version of dotnet core

---

## Steps

Next, you’ll add a new file to this repository.

1. Pull the code
2. Ensure connection string to database is correct
3. Ensure Rebex is running and IP address Port & password are configure correctly
4. Run the code (debug)
